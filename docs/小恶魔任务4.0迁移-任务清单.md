## 一、背景与现状对比

| 维度 | reborn（现状，旧版任务） | shattered1（目标，v4.x 新版） |
|---|---|---|
| 接取方式 | 17~19 层随机站位 NPC，对话接取 | 生成 9×9 专属房间 `AmbitiousImpRoom`，内有通往支线层的传送点 |
| 任务内容 | 杀 Striker/Manti 集 5（或 4）个矮人令牌 | 进入 VaultLevel 金库层探险，计分制（满分 4000） |
| 奖励 | 随机戒指 +2（诅咒） | 6 件高级装备备选（神器+5 / 戒指 / T5 武器 / 板甲 / 法杖），按分数可选 |
| Quest 存储 | `Dungeons.cur().impQuest` 实例成员 | `Imp.Quest` 静态字段 |
| 出口系统 | `Level.entrance/exit` 单点；**LevelTransition/Dungeon.branch 基础设施已补齐**（InterlevelScene 未接入） | `LevelTransition` 多传送点 + `Dungeon.branch` 支线层 |
| 关键道具 | 仅 DwarfToken | DwarfToken + EscapeCrystal + ImpStatue + VaultBeacon |
| 商店解锁 | 无对接 | `earnedShop()` → ImpShopkeeper / ImpShopRoom（reborn 已有此类，需对接） |
| 分数系统 | 无 `Statistics.questScores` | `Statistics.questScores[3]` 计入排名 |
| 对话 | 改版剧情 `P7_Plot_L1/L2` + `WndDialog` | `WndQuest` + messages 文案 |

**最大障碍**：~~reborn 没有 `LevelTransition`/`Dungeon.branch` 支线层架构~~ → 已补齐（见阶段 2.0）；剩余障碍是 `InterlevelScene` 支线切换与 `Statistics.questScores`。

## 四、风险点

1. ~~**LevelTransition 移植牵一发动全身**~~ → 已落地（阶段 2.0，存档带 contains 保护，旧档兼容）；剩余 `InterlevelScene` 改造仍是接入阶段最大工作量项
2. **存档格式不兼容**：reborn 现有 `demon` node 结构与新版不同，必须走 `old_quest` 兼容分支，否则旧档坏档
3. **API 版本鸿沟**：shattered1 基于较新 shattered，大量方法签名（`Dungeon.hero` vs `Dungeon.hero()`、`Messages.get` 重载、`Random.IntRange` 等）需逐处机械适配
4. **改版特有内容冲突**：reborn 的少女前线怪物（Striker/Manti）替换了原版 Monk/Golem，VaultLevel 怪物波次表引用的原版类若被改版删除需同步替换
5. **分数系统缺失**：`Statistics.questScores` 在 reborn 不存在，涉及存档与结算界面
